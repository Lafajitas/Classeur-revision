Objectifs de la séance

  • Lister les hypothèses du modèle de régression linéaire classique qui rendent les MCO « BLUE ».
  • Multicolinéarité : conséquences, détection (corrélations, VIF), remèdes.
  • Hétéroscédasticité : conséquences, détection (tests de Breusch-Pagan et de White), remède (erreurs-types robustes).

Lien avec J2 : c'est le « LINE » des résidus (Linéarité, Indépendance, Normalité, Égalité des variances), complété et testé formellement.

PARTIE 1Les hypothèses du modèle linéaire classique

Si elles sont vérifiées, les estimateurs MCO sont BLUE : Best Linear Unbiased Estimators, c'est-à-dire sans biais et de variance minimale parmi les estimateurs linéaires.

#HypothèseEn formuleSi elle est violée
1Modèle linéaire dans les paramètres (les X peuvent être au carré)\(Y_i=\beta_0+\beta_1X_{1i}+\beta_2X_{2i}^2+\dots+\varepsilon_i\)MCO inadaptés
2Pas de multicolinéarité parfaite : aucune relation linéaire exacte entre les Xpas de \(X_1 = a + bX_2\)Multicolinéarité
3Homoscédasticité : variance de l'erreur constante\(\text{var}(\varepsilon_i\mid X)=\sigma^2\)Hétéroscédasticité
4Erreur non corrélée aux X (exogénéité)\(E(\varepsilon_i\mid X)=0\)Endogénéité
5Pas d'autocorrélation entre les erreurs\(\text{cov}(\varepsilon_i,\varepsilon_j\mid X)=0,\ i\ne j\)Autocorrélation
6Erreur normale\(\varepsilon_i\sim N(0,\sigma^2)\)Tests t et F moins fiables en petit échantillon
Lire un graphe de résidus : nuage en bande horizontale régulière → OK ; entonnoir (l'écart grandit avec X) → hétéroscédasticité ; résidus qui montent avec X ou forment des vagues → erreurs non indépendantes (endogénéité, autocorrélation).

Le cours détaille trois problèmes : multicolinéarité, hétéroscédasticité et endogénéité (cette dernière est seulement citée dans ce support).

PARTIE 2La multicolinéarité

2.1 Définition

Il y a multicolinéarité quand des variables explicatives sont liées linéairement entre elles.

  • Parfaite : relation exacte. Ex. \(X_{1i} + X_{2i} = 1 \Leftrightarrow X_{1i} = 1 - X_{2i}\) (comme mettre « homme » et « femme » avec la constante). Les coefficients ne peuvent pas être estimés.
  • Imparfaite : forte corrélation sans être exacte (âge de la femme et âge du mari). Les coefficients s'estiment, mais mal.

2.2 Conséquences

  • Les MCO restent BLUE (sans biais), mais leurs variances sont grandes → erreurs-types élevées → t faibles → coefficients souvent non significatifs alors que les variables comptent.
  • Il devient difficile d'isoler l'effet propre de chaque variable sur Y : les deux X bougent ensemble.
\[ t_{STAT} = \frac{b_1-\beta_1}{S_{b_1}} \quad\Rightarrow\quad S_{b_1}\ \text{gonflé} \;\Rightarrow\; t\ \text{petit} \;\Rightarrow\; \text{non-rejet de } H_0 \]

2.3 Détection

Il n'existe pas de test unique. Deux outils :

  1. Corrélations deux à deux entre X élevées (en valeur absolue, proche de 1 ; repère courant : au-delà de 0,8).
  2. Le VIF (variance inflation factor) : de combien la variance de l'estimateur est gonflée par la colinéarité.
\[ VIF = \frac{1}{1-r_{23}^2} \] r₂₃ = corrélation entre X₂ et X₃ (cas de 2 X). Avec plusieurs X : \(VIF_j = \frac{1}{1-R_j^2}\), R²ⱼ = r² de la régression de Xⱼ sur les autres X.
\[ \text{var}(b_2) = \frac{\sigma^2}{\sum x_{2i}^2}\times VIF \] Tolérance = 1 / VIF (colonne « 1/VIF »).
r₂₃00,500,700,800,900,950,990,9951
VIF11,331,962,785,2610,2650,25100non défini

Exemple de calcul : r = 0,90 → \(1/(1-0{,}81) = 1/0{,}19 = 5{,}26\) : la variance de b₂ est 5,26 fois plus grande que sans colinéarité. Repères usuels : VIF > 5 → à surveiller ; VIF > 10 → forte multicolinéarité.

2.4 Remèdes

  • Ne rien faire, souvent la bonne réponse : si la colinéarité est modérée, ou si elle ne touche pas la variable qui nous intéresse (ex. on étudie l'effet de corruption, peu importe que deux variables de contrôle soient corrélées). Cas d'un modèle quadratique ou à interaction : age et age² sont forcément corrélés, c'est voulu (sleep = β₀ + β₁ totwrk + β₂ educ + β₃ age + β₄ age² + β₅ male + ε).
  • Retirer une des variables colinéaires du modèle.

PARTIE 4L'hétéroscédasticité

Hétéro-scédasticité = variance inégale du terme d'erreur : la dispersion des points autour de la droite change avec X (graphe en entonnoir). L'inverse, variance constante, est l'homoscédasticité.

Conséquences

  • Les MCO restent sans biais mais ne sont plus de variance minimale : ils ne sont plus BLUE, seulement LUE (linear unbiased estimators).
  • Les erreurs-types calculées sont fausses → les tests t et F ne sont plus fiables → risque de conclusions erronées sur la significativité des coefficients.
Ne pas confondre : multicolinéarité → les coefficients restent BLUE mais avec de grandes variances ; hétéroscédasticité → les coefficients ne sont plus BLUE et les erreurs-types usuelles sont fausses.

PARTIE 5Détection : tests de Breusch-Pagan et de White

Test de Breusch-Pagan
  1. Estimer le modèle par MCO, récupérer les résidus au carré \(e_i^2\).
  2. Régresser \(e_i^2\) sur les k variables X du modèle : \(e_i^2 = \alpha_0 + \alpha_1X_{1i} + \dots + \alpha_kX_{ki} + v_i\)
  3. H₀ : α₁ = α₂ = … = αₖ = 0 (homoscédasticité) ; H₁ : au moins un αᵢ ≠ 0.
  4. Regarder le F de cette régression : p-value ≤ α → rejet de H₀ → hétéroscédasticité ; p-value > α → on ne rejette pas → homoscédasticité.
Test de White (version abrégée du cours)
  1. Estimer le modèle par MCO, récupérer \(e_i^2\) et les valeurs prédites \(\hat Y_i\).
  2. Régresser \(e_i^2\) sur \(\hat Y\) et \(\hat Y^2\) : \(e_i^2 = \alpha_1 + \alpha_2\hat Y_i + \alpha_3\hat Y_i^2 + v_i\)
  3. H₀ : α₂ = α₃ = 0 (homoscédasticité) ; H₁ : au moins un ≠ 0.
  4. Même règle sur le F : significatif → hétéroscédasticité.
F de la régression auxiliaire, à partir de son R² : \[ F = \frac{R^2_{aux}/k}{(1-R^2_{aux})/(n-k-1)} \qquad df = (k\ ;\ n-k-1) \]
Exemple du cours — taux d'avortement dans les 50 États américains (1992)

ABR = B₁ + B₂ Religion + B₃ Price + B₄ Laws + B₅ Funds + B₆ Educ + B₇ Income + B₈ Picket + u (n = 50, k = 7).

  • MCO : R² = 0,577 ; seules Income (p = 0,0000) et Picket (p = 0,0083) sont significatives à 5 % ; Price p = 0,0635.
  • Breusch-Pagan : régression de RESID² sur les 7 X : R² = 0,320, F = 2,8238, p = 0,0167 < 0,05 → rejet de H₀ → hétéroscédasticité.
  • White : régression de RES² sur ABORTIONF et ABORTIONF² : R² = 0,193, F = 5,6232, p = 0,0065 < 0,05 → hétéroscédasticité confirmée.

PARTIE 6Remède : les erreurs-types robustes (White)

Exercice 1 — Calculer et lire un VIF

a. Dans l'exemple heures de travail, corr(age, husage) = 0,8881. Calculer le VIF « à deux variables ».
  1. \(r^2 = 0{,}8881^2 = 0{,}7887\)
  2. \(VIF = \dfrac{1}{1-0{,}7887} = \dfrac{1}{0{,}2113} = \mathbf{4{,}73}\)
  3. Lecture : la variance de b(age) est environ 4,7 fois plus grande que si age et husage n'étaient pas corrélés.
b. Stata affiche VIF(age) = 5,05. Pourquoi pas 4,73 ? Que vaut le R² de la régression auxiliaire ?
  1. Avec plusieurs X, le VIF utilise le R² de la régression de age sur toutes les autres X (kids6, husage, educ…), pas seulement sur husage : il est donc un peu plus élevé.
  2. \(VIF = \dfrac{1}{1-R^2_{age}} \Rightarrow R^2_{age} = 1 - \dfrac{1}{5{,}05} = 1 - 0{,}198 = \mathbf{0{,}802}\) : 80 % de la variation de l'âge de la femme est expliquée par les autres X. La tolérance (1/VIF) vaut 0,198, comme dans la sortie.
c. Avec r = 0,95, de combien l'erreur-type est-elle gonflée ?
  1. VIF = 1 / (1 − 0,9025) = 10,26 → la variance est multipliée par 10,26.
  2. L'erreur-type est la racine de la variance : multipliée par \(\sqrt{10{,}26} = \mathbf{3{,}2}\). Le t est donc divisé par environ 3,2 : un coefficient avec t = 4 sans colinéarité tomberait à t ≈ 1,25 (non significatif).

Exercice 2 — Diagnostiquer et corriger la multicolinéarité (heures de travail)

a. Dans le modèle 1, quel coefficient paraît suspect ?

husage : b = −2,66, t = −0,38, p = 0,707 → non significatif. Tests t : df = 753 − 7 − 1 = 745, t critique ≈ ± 1,963 ; |−0,38| < 1,963. Pourtant le modèle est globalement très significatif (F = 55,72) : un X non significatif dans un bon modèle doit faire penser à la colinéarité.

b. Confirmer avec les corrélations et les VIF.
  1. Matrice de corrélation : corr(age, husage) = 0,8881, très au-dessus de toutes les autres paires de X (max 0,44 en valeur absolue).
  2. VIF : age = 5,05 et husage = 4,86, les deux plus élevés, nettement au-dessus des autres (≈ 1,2–1,3) → multicolinéarité entre age et husage.
c. Remède et comparaison.
  1. Remède : retirer husage (variable de contrôle, pas la variable d'intérêt ; l'âge de la femme est plus pertinent pour ses propres heures de travail).
  2. VIF du modèle 2 : tous ≤ 1,41 → problème réglé.
  3. Erreur-type de age : 7,198 → 3,803. Rapport des variances : \((7{,}198/3{,}803)^2 = 1{,}893^2 = 3{,}58\) : la variance de b(age) a été divisée par 3,6.
  4. t de age : \(-25{,}71/7{,}198 = -3{,}57\) → \(-28{,}01/3{,}803 = -7{,}37\) : effet bien plus précis.
  5. R² : 0,3436 → 0,3435 (quasi identique) ; R² ajusté : 0,3375 → 0,3382 (meilleur) : le modèle sans husage est préférable.
d. Interpréter le modèle 2 (unités : heures par an).
  • kids6 : chaque enfant de moins de 6 ans réduit les heures travaillées de 357 h/an en moyenne, les autres X constants.
  • age : chaque année d'âge en plus → −28 h/an.
  • exper : chaque année d'expérience → +41,8 h/an ; wage : +1 $ de salaire horaire → +75,8 h/an.
  • faminc : +1 000 $ de revenu familial → +8,7 h/an.
  • educ : −23,4 h par année d'études, mais p = 0,069 → non significatif à 5 %.

Exercice 3 — Test de Breusch-Pagan (avortement)

Régression auxiliaire de RESID² sur les 7 X : R² = 0,320022, n = 50.

  1. Hypothèses : H₀ : α₁ = … = α₇ = 0 (homoscédasticité) ; H₁ : au moins un αᵢ ≠ 0.
  2. Statistique : \(F = \dfrac{0{,}320022/7}{(1-0{,}320022)/(50-7-1)} = \dfrac{0{,}045717}{0{,}016190} = \mathbf{2{,}824}\) (= la sortie EViews).
  3. Degrés de liberté : (7 ; 42). Valeur critique à 5 % : F = 2,237 (Excel =INVERSE.LOI.F.N(0,95;7;42)).
  4. Décision : 2,824 > 2,237 et p = 0,0167 < 0,05 → rejet de H₀.
  5. Conclusion : les erreurs sont hétéroscédastiques ; les tests t de la régression MCO ne sont pas fiables.

Variante « Obs*R-squared » : n × R² = 50 × 0,320022 = 16,00, comparé à χ²(7) = 14,07 → même conclusion (p = 0,0251).

Exercice 4 — Test de White et erreurs-types robustes (avortement)

a. Régression de RES² sur ABORTIONF et ABORTIONF² : R² = 0,193083. Conclure.
  1. H₀ : α₂ = α₃ = 0 ; H₁ : au moins un ≠ 0.
  2. \(F = \dfrac{0{,}193083/2}{(1-0{,}193083)/(50-2-1)} = \dfrac{0{,}096542}{0{,}017169} = \mathbf{5{,}623}\)
  3. df = (2 ; 47) ; F critique 5 % = 3,195. 5,623 > 3,195 et p = 0,0065 < 0,05 → rejet de H₀ : hétéroscédasticité, même conclusion que Breusch-Pagan.
b. Que change le passage aux erreurs-types robustes pour Price ?
  1. Le coefficient reste −0,042363 (les coefficients ne changent jamais).
  2. MCO : \(t = -0{,}042363/0{,}022223 = -1{,}906\) ; p = 0,0635.
  3. Robuste : \(t = -0{,}042363/0{,}025944 = -1{,}633\) ; p = 0,110.
  4. Conclusion : avec les MCO on aurait dit « le prix réduit le taux d'avortement, significatif à 10 % » ; une fois l'hétéroscédasticité corrigée, Price n'est significatif à aucun seuil usuel. Income (p = 0,0000) et Picket (p = 0,0060) restent significatifs : ces conclusions sont solides.
