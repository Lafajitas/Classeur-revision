PARTIE 1Introduction

1.1 Qu'est-ce que l'économétrie ?

Économétrie = théorie économique + données économiques + outils de recherche → quantifier des relations économiques, tester des hypothèses économiques, prédire des résultats économiques.

Exemple fil rouge : taille de classe → moyenne (GPA) des élèves.

  1. Théorie / expérience : quels éléments influencent le GPA ? (taille de classe, qualité de l'enseignant, dispositifs de soutien…)
  2. Collecter les données
  3. Outils de recherche → quantifier (réduire la classe d'1 élève : effet sur le GPA ?), tester, prédire.

Autres questions typiques : réduire la taille des classes améliore-t-il l'école primaire ? Effet d'une année d'études en plus sur le salaire ? Une campagne de pub augmente-t-elle les ventes ? Quels facteurs influencent l'efficacité / la liquidité bancaire ?

1.2 Étapes de l'analyse économique empirique

Théorie éco / relation importante→Modèle mathématique→Modèle économétrique→Données→Estimation→Tests d'hypothèse + intervalle de confiance→Prévision→Usage pour contrôle / politique

En bleu : les étapes au cœur du cours.

Exemple : Keynes, consommation et revenu
  • Théorie : les individus augmentent leur consommation quand leur revenu augmente, mais moins que la hausse du revenu. Revenu +1 → consommation + (moins de 1).
  • Modèle mathématique : \(Y = \beta_0 + \beta_1 X,\quad 0 < \beta_1 < 1\) (Consommation = β₀ + β₁·Revenu).
  • Modèle économétrique : la consommation dépend aussi de la taille de la famille, de l'âge des membres, de la religion… → \(Y = \beta_0 + \beta_1 X + u\), où u représente tous les facteurs qui affectent la consommation sans être pris en compte explicitement.
  • Données : 500 familles américaines, nuage de points. Population = tous les individus sur lesquels on veut conclure ; échantillon = la partie sélectionnée pour l'analyse.
  • Estimation (régression) : \(\hat Y = -184.08 + 0.7064\,X_i\) → +1 $ de revenu réel ⇒ en moyenne ≈ +70 cents de consommation réelle.
  • Test / IC : Keynes attend β₁ positif mais < 1 ; on trouve ≈ 0,70. Il faut vérifier que ce n'est pas le hasard des données utilisées → tester : 0,70 est-il statistiquement inférieur à 1 ? + estimer un intervalle de confiance.
  • Prévision : si le modèle ne réfute pas l'hypothèse, on prédit Y à partir de X. X attendu = 6 500 $ ⇒ \(\hat Y = -184.08 + 0.7064 \times 6500 = 4407.52\).

1.3 Données

Sources
  • Expérimentales : issues d'expériences conçues pour évaluer un traitement/une politique ou étudier un effet causal (ex. : quantité d'engrais → rendement des tomates).
  • Observationnelles : collectées par enquêtes et registres administratifs.
Types
  • Coupe transversale (cross-sectional) : plusieurs entités, une seule période (ex. : salaire, éducation, expérience, sexe, statut marital de 526 individus).
  • Série temporelle (time series) : une seule entité, plusieurs périodes (ex. : PIB réel US annuel 1980–2008).
  • Panel : plusieurs entités, chacune observée à 2 périodes ou plus (ex. : criminalité de 150 villes en 1986 et 1990).

PARTIE 2Mesures descriptives numériques

2.1 Définitions

  • Population : tous les éléments/individus sur lesquels on veut conclure. Échantillon : portion de la population sélectionnée pour l'analyse (le « petit groupe »). Ex. revenu → consommation dans un pays : population = tous les individus > 18 ans ; échantillon = certains d'entre eux.
  • Tendance centrale : degré auquel les valeurs se regroupent autour d'une valeur typique/centrale → moyenne, médiane, mode.
  • Variation : dispersion des valeurs → étendue, variance, écart-type.

2.2 Tendance centrale (échantillon)

MesureDéfinitionPropriétés
Moyenne (arithmétique, « x-bar »)\(\bar X = \dfrac{\sum_{i=1}^{n} X_i}{n} = \dfrac{X_1 + \dots + X_n}{n}\)Mesure la plus courante ; n = taille de l'échantillon, Xᵢ = i-ème valeur observée
MédianeValeur du « milieu » d'une série ordonnée (50 % au-dessus, 50 % en dessous)Non affectée par les valeurs extrêmes (11,12,13,14,15 et 11,12,13,14,20 → médiane = 13 dans les deux cas)
ModeValeur la plus fréquenteNon affecté par les valeurs extrêmes ; utilisable pour données numériques ou catégorielles ; il peut n'y avoir aucun mode ou plusieurs
Exemple : prix de maisons2 000 000 · 500 000 · 300 000 · 100 000 · 100 000 (somme 3 000 000) → moyenne = 3 000 000 / 5 = 600 000 $ ; médiane = 300 000 ; mode = 100 000. La moyenne est tirée vers le haut par la valeur extrême.

2.3 Variation (échantillon)

Renseigne sur l'étalement / la dispersion des données (même centre possible avec des variations différentes).

  • Étendue (range) : mesure la plus simple. \(\text{Range} = X_{\text{largest}} - X_{\text{smallest}}\). Ex. : 13 − 1 = 12.
  • Variance d'échantillon : moyenne (approximativement) des carrés des écarts à la moyenne :
    \[ S^2 = \frac{\sum_{i=1}^{n}(X_i - \bar X)^2}{n-1} \]
  • Écart-type d'échantillon : mesure de variation la plus utilisée ; montre la variation autour de la moyenne ; racine carrée de la variance ; même unité que les données.
    \[ S = \sqrt{\frac{\sum_{i=1}^{n}(X_i - \bar X)^2}{n-1}} \]
Variance – prix maisons (k$)Écarts : 1 400 ; −100 ; −300 ; −500 ; −500. Carrés : 1 960 000 ; 10 000 ; 90 000 ; 250 000 ; 250 000. Somme = 2 560 000 → variance affichée = 640 000 (= 2 560 000 / 4, soit n − 1).
Écart-type – exemple10, 12, 14, 15, 17, 18, 18, 24 ; n = 8 ; \(\bar X = 16\). \(S = \sqrt{\tfrac{(10-16)^2+\dots+(24-16)^2}{8-1}} = \sqrt{\tfrac{130}{7}} = \mathbf{4.3095}\) → dispersion « moyenne » autour de la moyenne.

Comparaison (données A, B, C sur 11–21) : B, très regroupée, a le plus petit écart-type ; C, concentrée aux deux extrémités, le plus grand.

2.4 – 2.6 Mesures pour une population

Les mesures d'une population s'appellent des paramètres et sont notées en lettres grecques (moyenne, variance, écart-type). N = taille de la population. On divise par N (et non n − 1).

MesureParamètre de populationStatistique d'échantillon
Moyenne\(\mu = \dfrac{\sum_{i=1}^{N} X_i}{N}\)\(\bar X = \dfrac{\sum_{i=1}^{n} X_i}{n}\)
Variance\(\sigma^2 = \dfrac{\sum_{i=1}^{N}(X_i-\mu)^2}{N}\)\(S^2 = \dfrac{\sum_{i=1}^{n}(X_i-\bar X)^2}{n-1}\)
Écart-type\(\sigma = \sqrt{\dfrac{\sum_{i=1}^{N}(X_i-\mu)^2}{N}}\)\(S = \sqrt{\dfrac{\sum_{i=1}^{n}(X_i-\bar X)^2}{n-1}}\)
Règle des 3 sigma (loi normale) : μ ± 1σ ≈ 68 % des valeurs · μ ± 2σ ≈ 95 % · μ ± 3σ ≈ 99,7 %.

2.7 Covariance

Mesure la force de la relation linéaire entre deux variables numériques X et Y.

\[ \operatorname{cov}(X,Y) = \frac{\sum_{i=1}^{n}(X_i-\bar X)(Y_i-\bar Y)}{n-1} \]
  • cov > 0 : X et Y tendent à varier dans le même sens ; cov < 0 : en sens opposé ; cov = 0 : X et Y indépendants (selon le cours).
  • Ne concerne que la force de la relation ; aucun effet causal n'est impliqué.
  • Défaut majeur : la taille de la covariance ne permet pas de juger la force relative de la relation.

2.8 Coefficient de corrélation

Mesure la force relative de la relation linéaire entre deux variables numériques.

\[ r = \frac{\operatorname{cov}(X,Y)}{S_X\,S_Y},\qquad S_X = \sqrt{\frac{\sum (X_i-\bar X)^2}{n-1}},\quad S_Y = \sqrt{\frac{\sum (Y_i-\bar Y)^2}{n-1}} \]
  • Population : ρ ; échantillon : r.
  • Compris entre −1 et 1. Proche de −1 : relation linéaire négative forte ; proche de 1 : positive forte ; proche de 0 : relation linéaire faible.
  • Nuages types : r = −1 (points alignés, pente négative), r = −0,6, r = +1 (alignés, pente positive), r = +0,3 (très dispersé), r = 0 (Y constant quand X varie).

PARTIE 3Estimation, tests d'hypothèse, intervalle de confiance

Test à 1 échantillon : comparer une moyenne à une valeur (ex. : poids moyen des sachets de thé =, > ou < 5,5 g ?). Test à 2 échantillons : comparer deux moyennes (ex. : salaire des hommes =, > ou < celui des femmes ?).

3.1 Estimation de la moyenne de population

  • Moyenne = espérance de Y : \(E(Y) = \mu_Y\).
  • Loi des grands nombres : quand n est grand, \(\bar Y \to \mu_Y\).

3.2 Test d'hypothèse — les 5 étapes

  1. Poser l'hypothèse nulle H₀ et l'hypothèse alternative H₁.
  2. Choisir le seuil de signification α = probabilité de rejeter H₀ alors qu'elle est vraie (1 %, 5 %, 10 %).
  3. Déterminer les valeurs critiques qui séparent zone de rejet et zone de non-rejet (test bilatéral : α/2 dans chaque queue).
  4. Calculer la statistique t.
  5. Si la statistique tombe dans la zone de non-rejet → ne pas rejeter H₀ ; dans la zone de rejet → rejeter H₀.
Règle de décision : rejeter H₀ si |t| ≥ valeur critique ⇔ si p-value ≤ α. (p < α : rejet ; p ≥ α : non-rejet.) « If the p-value is low, H₀ must go. »
1 échantillon — test pour μ
  • σ connu → test Z
  • σ inconnu → test t :
\[ t_{STAT} = \frac{\bar Y - \mu}{S/\sqrt n} \]

degrés de liberté : df = n − 1

2 échantillons (A et B, indépendants)
\[ t = \frac{\bar Y_A - \bar Y_B}{\sqrt{\frac{s_A^2}{n_A}+\frac{s_B^2}{n_B}}} = \frac{\bar Y_A - \bar Y_B}{SE(\bar Y_A - \bar Y_B)} \]

SE = erreur-type (standard error) ; \(s_A^2 = \frac{1}{n_A-1}\sum_{i=1}^{n_A}(Y_i-\bar Y_A)^2\)

Formes de H₀ / H₁ (deux moyennes, échantillons indépendants)

TestH₀H₁Rejeter H₀ si
Unilatéral à gaucheμ₁ − μ₂ ≥ 0μ₁ − μ₂ < 0tSTAT < −tα
Unilatéral à droiteμ₁ − μ₂ ≤ 0μ₁ − μ₂ > 0tSTAT > tα
Bilatéralμ₁ − μ₂ = 0μ₁ − μ₂ ≠ 0tSTAT < −tα/2 ou tSTAT > tα/2

3.3 Intervalle de confiance

  • Estimation ponctuelle = un seul nombre ; l'IC ajoute une information sur la variabilité de l'estimation (bornes inférieure et supérieure ; niveau 95 %, 99 %…).
\[ \text{Estimation ponctuelle} \pm (\text{Valeur critique}) \times (\text{Erreur-type}) \]
Exemple 1 échantillon : hôtels à New York Coût moyen annoncé 168 $/nuit. Échantillon de n = 25 hôtels : \(\bar Y = 172.50\), S = 15.40 ; α = 0,05 ; population supposée normale.
  • H₀ : μ = 168 ; H₁ : μ ≠ 168
  • df = 24 ; valeurs critiques ± t24 ; 0,025 = ± 2,0639
  • \(t_{STAT} = \dfrac{172.50 - 168}{15.40/\sqrt{25}} = 1.46\)
  • −2,0639 < 1,46 < 2,0639 → ne pas rejeter H₀ : pas assez de preuves que le coût moyen diffère de 168 $.
  • IC 95 % : \(172.5 \pm 2.0639 \times 15.4/\sqrt{25}\) → 166,14 ≤ μ ≤ 178,86 (contient 168).
Logiciel (XLSTAT, captures du cours) Menu « Parametric tests » → One-sample t-test and z-test ou Two-sample t-test and z-test. Onglet General : sélectionner les données (ex. variable Teabags ; ou Data = testscr, Sample identifiers = group, « One column per variable »), cocher Column labels, choisir Student's t test. Onglet Options : hypothèse alternative (Mean 1 ≠ Theoretical mean, ou Mean 1 − Mean 2 ≠ D), moyenne théorique / différence D (0), seuil 5 %. 3.4 Exemple : taille des classes et résultats scolaires (Californie)

Question politique : effet sur les scores d'une réduction de la taille des classes d'1 élève ? de 8 élèves ?
Données : tous les districts K-6 et K-8 de Californie (n = 420). Variables : score moyen de 5e année au test Stanford-9 (maths + lecture) ; STR (student-teacher ratio) = nb d'élèves / nb d'enseignants équivalent temps plein.
Nuage de points score vs STR : relation négative (droite décroissante), mais très dispersée.

Démarche : (1) comparer les scores moyens STR faible vs élevé = estimation ; (2) tester que les moyennes sont égales vs différentes = test ; (3) intervalle pour la différence = IC.

Taille de classeScore moyen \(\bar Y\)Écart-type sYn
Petite (STR < 20)657,419,4238
Grande (STR ≥ 20)650,017,9182
  1. Estimation : \(\Delta = \bar Y_{small} - \bar Y_{large} = 657.4 - 650.0 = 7.4\). Est-ce important dans la réalité (réforme, parents, comité scolaire) ? → test de différence de moyennes.
  2. Test : H₀ : Δ = 0 (pas de différence) ; H₁ : Δ ≠ 0 ; α = 5 % ; valeur critique = 1,96.
    \[ t = \frac{657.4 - 650.0}{\sqrt{\frac{19.4^2}{238} + \frac{17.9^2}{182}}} = \frac{7.4}{1.83} = 4.05 \]
    |t| = 4,05 > 1,96 → on rejette H₀ au seuil de 5 % : les deux moyennes ne sont pas égales.
  3. IC à 95 % : \((\bar Y_s - \bar Y_l) \pm 1.96 \times SE = 7.4 \pm 1.96 \times 1.83 = (3.8\,;\,11.0)\).
    Deux affirmations équivalentes : l'IC à 95 % de Δ ne contient pas 0 ⇔ Δ = 0 est rejetée à 5 %.

RÉCAPÀ savoir faire

  • Distinguer données transversales, temporelles, de panel (et expérimentales vs observationnelles).
  • Calculer et interpréter : moyenne, médiane, mode ; étendue, variance, écart-type (n − 1 pour l'échantillon, N pour la population) ; covariance, corrélation.
  • Estimer une moyenne de population, mener un test d'hypothèse en 5 étapes et l'interpréter (|t| vs valeur critique, p-value vs α).
  • Construire un intervalle de confiance : estimation ± valeur critique × erreur-type.
