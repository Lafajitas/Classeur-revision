Régression linéaire multiple

Objectifs de la séance

  • Construire un modèle de régression multiple (plusieurs X pour un seul Y).
  • Interpréter les coefficients « toutes choses égales par ailleurs ».
  • Juger quelles variables comptent : test F global puis tests t individuels.
  • Utiliser des variables qualitatives (variables muettes / dummies).
  • Expliquer une interaction entre deux variables indépendantes.

Différence avec J2 : en régression simple, b₁ mélange l'effet de X avec celui de tout ce qui varie en même temps que X. En régression multiple, chaque pente mesure l'effet de sa variable en tenant les autres constantes.

PARTIE 1Le modèle de régression multiple

1.1 Modèle de population (k variables indépendantes)

\[ Y_i = \underbrace{\beta_0}_{\text{intercept}} + \underbrace{\beta_1 X_{1i} + \beta_2 X_{2i} + \dots + \beta_k X_{ki}}_{\text{pentes de la population}} + \underbrace{\varepsilon_i}_{\text{erreur aléatoire}} \]

On étudie la relation linéaire entre une variable dépendante Y et deux ou plus variables indépendantes Xj.

1.2 Équation estimée

Les coefficients sont estimés sur l'échantillon (toujours par les moindres carrés, min Σ(Yᵢ − Ŷᵢ)²) :

\[ \hat Y_i = b_0 + b_1 X_{1i} + b_2 X_{2i} + \dots + b_k X_{ki} \]

\(\hat Y_i\) = valeur prédite de Y ; b₀ = intercept estimé ; b₁ … bk = pentes estimées.

1.3 Interpréter une pente

bj = variation moyenne estimée de Y quand Xj augmente d'une unité, les autres X restant constants (« net of the effects of changes due to the other variables », « ceteris paribus »).
Toujours : le signe, la taille dans les unités de Y et de X, « en moyenne », et « à … constant ».

PARTIE 3Coefficient de détermination : r² et r² ajusté

3.1 r² multiple

\[ r^2 = \frac{SSR}{SST} = \frac{\text{somme des carrés de la régression}}{\text{somme des carrés totale}} = \frac{29\,460{,}0}{56\,493{,}3} = \mathbf{0{,}52148} \]

52,1 % de la variation des ventes de tartes est expliquée par la variation du prix et de la publicité prises ensemble.

3.2 Pourquoi un r² ajusté ?

Le r² ne diminue jamais quand on ajoute une variable X, même inutile. C'est un défaut pour comparer des modèles qui n'ont pas le même nombre de variables.

\[ r^2_{adj} = 1 - \left[(1 - r^2)\left(\frac{n-1}{n-k-1}\right)\right] \qquad n = \text{taille de l'échantillon},\; k = \text{nombre de X} \]
\[ r^2_{adj} = 1 - (1 - 0{,}52148)\times\frac{14}{12} = \mathbf{0{,}44172} \]
  • Pénalise l'ajout de variables peu utiles ; toujours inférieur au r².
  • Sert à comparer des modèles : on garde celui au r² ajusté le plus élevé.
  • Lecture : 44,2 % de la variation des ventes est expliquée par le prix et la publicité, compte tenu de la taille de l'échantillon et du nombre de variables.

PARTIE 4Le modèle est-il significatif ? Test F global

Le test F regarde si toutes les X prises ensemble ont une relation linéaire avec Y.

\[ H_0 : \beta_1 = \beta_2 = \dots = \beta_k = 0 \quad(\text{aucune relation linéaire}) \qquad H_1 : \text{au moins un } \beta_j \neq 0 \]
\[ F_{STAT} = \frac{MSR}{MSE} = \frac{SSR / k}{SSE / (n-k-1)} \qquad df = (k\,;\,n-k-1) \]

SSR = variation expliquée ; SSE = variation non expliquée. Dans Excel, la p-value du test F s'appelle Significance F.

Exemple tartes \[ F_{STAT} = \frac{14\,730{,}0}{2\,252{,}8} = 6{,}5386 \qquad df = (2\,;\,12) \qquad F_{0{,}05} = 3{,}885 \] 6,54 > 3,885 et Significance F = 0,0120 < 0,05 → on rejette H₀ : au moins une des deux variables (prix ou pub) est liée aux ventes.
Règle de décision : rejet de H₀ si FSTAT > F critique ⇔ Significance F < α. Valeur critique dans Excel : =INVERSE.LOI.F.DROITE(0,05;k;n-k-1).

PARTIE 5Les variables sont-elles significatives une à une ? Tests t

Le test t sur bj regarde s'il existe une relation linéaire entre Xj et Y en tenant constants les effets des autres X.

\[ H_0 : \beta_j = 0 \qquad H_1 : \beta_j \neq 0 \qquad t_{STAT} = \frac{b_j - 0}{S_{b_j}} \qquad df = n - k - 1 \]

Intervalle de confiance d'une pente : \(b_j \pm t_{\alpha/2;\,n-k-1}\,S_{b_j}\). Pour le prix : [−48,58 ; −1,37], qui ne contient pas 0 → même conclusion que le test.

F d'abord, t ensuite. Le test F répond à « le modèle sert-il à quelque chose ? » ; les tests t à « quelles variables apportent une contribution significative, à autres variables constantes ? ». On peut avoir un F significatif avec une variable non significative : il faut alors interpréter seulement les significatives (ou retirer les autres et comparer les r² ajustés).

5.1 Résumé du cours

  • r² : % de la variation de Y expliquée par l'ensemble des X ; augmente toujours quand on ajoute un X.
  • r² ajusté : même idée, corrigé de n et de k ; sert à comparer des modèles.
  • Test F : significativité globale (H₀ : tous les β = 0).
  • Test t : significativité de chaque variable.

PARTIE 6Variables qualitatives : les variables muettes (dummies)

6.1 Principe

  • Une variable muette est une variable catégorielle à deux niveaux (oui/non, homme/femme…) codée 0 ou 1.
  • On suppose que les pentes des variables numériques ne changent pas selon la catégorie : seule l'ordonnée à l'origine change.
  • S'il y a plus de deux niveaux, il faut (nombre de niveaux − 1) variables muettes.

6.2 Deux niveaux : la semaine de fête (Holiday)

Y = ventes de tartes ; X₁ = prix ; X₂ = 1 si une fête a eu lieu dans la semaine, 0 sinon.

\[ \text{Fête } (X_2 = 1) : \hat Y = b_0 + b_1X_1 + b_2(1) = (b_0 + b_2) + b_1X_1 \]\[ \text{Pas de fête } (X_2 = 0) : \hat Y = b_0 + b_1X_1 + b_2(0) = b_0 + b_1X_1 \]

Même pente b₁, ordonnées différentes (b₀ + b₂ contre b₀) : deux droites parallèles, écartées de b₂. Si on rejette H₀ : β₂ = 0, la fête a un effet significatif sur les ventes.

Exemple du cours \[ \widehat{Sales} = 465 - 13\,(Price) + 81\,(Holiday) \] b₂ = 81 : en moyenne, on vend 81 tartes de plus les semaines avec une fête que les semaines sans fête, à prix égal.

6.3 Plus de deux niveaux : la localisation d'une maison

Y = prix de la maison ; X₁ = surface (sq ft) ; localisation : district 1, 2 ou 3 → 3 niveaux, donc 2 variables muettes. District 1 = catégorie de référence :

\[ \hat Y = 101 + 0{,}14X_1 - 104X_2 - 53X_3 \]
  • District 1 : \(\hat Y = 101 + 0{,}14X_1\)
  • District 2 : \(\hat Y = 101 + 0{,}14X_1 - 104\) → à surface égale, une maison du district 2 vaut en moyenne 104 k$ de moins qu'une maison du district 1.
  • District 3 : \(\hat Y = 101 + 0{,}14X_1 - 53\) → 53 k$ de moins qu'au district 1, à surface égale.
Piège de la variable muette (dummy trap) : ne jamais mettre les 3 indicatrices (Var 1, Var 2, Var 3) avec l'intercept. Leur somme vaut toujours 1 : colinéarité parfaite, Excel ne peut pas estimer le modèle. On en retire une, qui devient la référence ; chaque coefficient se lit par rapport à elle.

6.4 Dans XLSTAT (ANCOVA) et dans Excel

  • XLSTAT → Modélisation → ANCOVA : Y en Quantitative, les X numériques en Quantitative, la variable catégorielle (ex. Holiday, Method) en Qualitative. Onglet Options → ANOVA/ANCOVA, contrainte a1 = 0 : la première catégorie devient la référence (son coefficient affiché vaut 0).
  • Excel seul : créer une colonne 0/1 par catégorie non de référence, par exemple =SI(C2="Web-based";1;0), puis Utilitaire d'analyse → Régression. Les colonnes X doivent être côte à côte.

PARTIE 7Interaction entre variables indépendantes

Question : l'effet d'une variable dépend-il du niveau d'une autre ? Exemples du cours : boire de l'alcool et fumer (risque de cancer de la gorge) ; la corruption décourage-t-elle davantage les femmes de demander un crédit ?

\[ \hat Y = b_0 + b_1(\text{smoke}) + b_2(\text{drink}) + b_3(\text{smoke})(\text{drink}) \]\[ \hat Y = b_0 + b_1(\text{corruption}) + b_2(\text{female}) + b_3(\text{corruption})(\text{female}) \]

7.1 Effet d'une variable avec interaction

\[ Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \beta_3X_1X_2 + \varepsilon \]
  • Sans terme d'interaction, l'effet de X₁ sur Y est mesuré par β₁.
  • Avec interaction, l'effet de X₁ sur Y est β₁ + β₃X₂ : il change quand X₂ change.
  • Si X₂ est une variable muette : pente de X₁ = β₁ quand X₂ = 0, et β₁ + β₃ quand X₂ = 1 → droites non parallèles.
  • On teste l'interaction par le test t sur β₃ (H₀ : β₃ = 0). Si on ne rejette pas H₀, l'interaction n'apporte rien : on revient au modèle sans interaction.
